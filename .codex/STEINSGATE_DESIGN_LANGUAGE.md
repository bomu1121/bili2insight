
# Steins;Gate 设计语言 · Design Language

> 「未来道具研究所」的视觉身份体系 —— 不是一个浅薄的"齿轮+CRT扫描线"主题，
> 而是一套完整的色彩架构、材质语言、角色映射和氛围系统。
>
> 本文档替代 CLAUDE.md 中对 Steins;Gate 的浅层理解，作为 bili2insight 所有视觉决策的权威参考。

---

## 0. 核心诊断：CLAUDE.md 的认知偏差

CLAUDE.md 将品牌色定义为 `#6fb584`（sage green / 收敛鼠尾草绿），将 UI 描述为
"温暖暗色调 + 收敛 Sage Green"。**这在 Steins;Gate 的视觉体系中没有对应物。**

Steins;Gate 中**不存在** sage green 作为品牌色的概念。绿色在作品中的角色是
**CRT 荧光绿**——专属于科技界面（PhoneWave 显示器、老式终端），是技术功能的信号色，
不是品牌身份色。把绿色当作品牌主色，相当于把《星际迷航》做成亮绿色主题因为它有绿色面板。

实际的核心色彩架构是：
- **暖琥珀/棕褐**（Lab 的氛围底色）—— 这是被 CLAUDE.md 完全遗漏的
- **栗红**（牧濑红莉栖）—— 视觉锚点，饱和色焦点
- **CRT 荧光绿**（技术界面）—— 功能性辅助色
- **辉光管橙**（世界线仪）—— 核心仪表色
- **冷蓝**（SERN/威胁）—— 对立面，叙事对比色

## 1. 色彩架构 · Color Architecture

### 1.1 主色调 —— Lab 的色彩（未来道具研究所）

未来道具研究所（秋叶原某杂居大楼）是全剧最核心的空间。它的色彩定义了
Steins;Gate 的默认氛围，也是 **bili2insight 暗色模式的配色基础**。

| 角色 | 色域 | 代表性 Hex | 来源 |
|------|------|-----------|------|
| **暖琥珀** | 琥珀→蜜色→金 | `#C4956A` `#D4A574` `#F5DEB3` | 白炽灯、午后阳光、旧木家具 |
| **深影** | 炭黑→深棕 | `#1A1512` `#1E1B18` `#24211D` | Lab 角落、CRT 外壳、暗木 |
| **暖白** | 奶油白→纸白 | `#F5F0EB` `#E8E0D5` | 白大褂、研究笔记、白炽灯照射面 |

**暗色模式应基于暖深棕/炭黑，而非冷蓝灰。** 当前 `#111316`（h216 冷色）与
Steins;Gate 的暖暗实验室氛围存在根本性的色温冲突。

### 1.2 人物锚点色

#### 牧濑红莉栖 · Kurisu Makise — 视觉焦点

Kurisu 是 Steins;Gate 的情感与视觉锚点。她在 Lab 场景中的出现总是画面的色彩焦点。

| 元素 | 色值范围 | 语义 |
|------|---------|------|
| **头发** | `#8B3A3A` ~ `#A0522D` (栗红/赤褐) | 知性、克制、内在的热 |
| **眼睛** | `#6B5B9E` ~ `#7B6DA8` (紫罗兰) | 神秘、"不可观测的变量" |
| **白大褂** | `#F5F0EB` (暖白, 非纯白) | 科学家的身份、专业 |
| **领带** | 深红 | 与头发呼应的色彩锚点 |
| **整体** | 红 + 紫 + 白 + 黑 | 冷峻外表 x 温暖内核 |

Kurisu 的红 **不是** 烈焰红（#FF0000），而是克制的、知性的栗红/赤褐色。
这是「冷美人的温度」——她表面冷淡，内核炽热。

**设计含义**：Kurisu 红应作为 bili2insight 的**主要交互信号色**——按钮、链接、
选中态、active 指示器——因为在 Steins;Gate 的视觉语法中，红 = 最重要的焦点。

#### 冈部伦太郎 · Okabe Rintaro

| 元素 | 色值 | 语义 |
|------|------|------|
| 白大褂 | `#F5F0EB` | Lab 的身份、疯狂科学家的伪装 |
| T恤 | 深灰/黑 | |
| **手机** | 老式翻盖 深银 | D-Mail 的触发器 |

#### 椎名真由理 · Mayuri Shiina

| 元素 | 色值 | 语义 |
|------|------|------|
| 连衣裙 | `#6B8FA3` ~ `#4A7A94` (柔蓝) | 温柔、日常、被保护的日常 |
| 帽子 | 深蓝 | |

Mayuri 蓝代表「需要守护的日常」——这也是叙事对比的一极。

### 1.3 世界线色彩

Steins;Gate 用 **色温** 作为叙事装置：

| 状态 | 色温 | 氛围 | 含义 |
|------|------|------|------|
| **Lab 日常** | 暖 (h30-h40) | 棕褐 + 琥珀 + 金 | 安全、人类连接、"真实"世界线 |
| **Steins;Gate 世界线** | 极暖/金色 | 午后金晖笼罩一切 | 希望、完美的结局、神圣 |
| **SERN/未来** | 冷 (h210-h220) | 灰蓝、冷荧光 | 体制、反乌托邦、必须避免的 |
| **电话微波炉启动** | 翠绿荧光 + 黑 | CRT 绿 + 深黑 | 技术、干涉、观测行为 |

**设计含义**：bili2insight 的暗色模式应走暖线（Lab 夜间），亮色模式应走
金色/暖白（Steins;Gate 世界线的午后光）。**冷蓝灰应该被限制在少量对立面元素
（如错误状态、外部威胁指示），而不是作为主色调。**

### 1.4 功能色体系

| 功能 | Steins;Gate 来源 | 推荐色值 (暗色) | 推荐色值 (亮色) |
|------|-----------------|---------------|---------------|
| **品牌/主交互** | Kurisu 栗红 | `#8B3E3E` | `#7B2D2D` |
| **技术/代码** | CRT 荧光绿 | `#4AE54A` | `#2A7A2A` |
| **世界线/仪表** | 辉光管橙 | `#FF8C42` | `#D4702A` |
| **数据/分析** | VN UI 青 | `#4AA3B8` | `#2A7A8C` |
| **成功/完成** | VN 系统确认 | `#4AE54A` | `#2A7A2A` |
| **警告/注意** | 辉光管暖橙 | `#FF8C42` | `#D4702A` |
| **错误/威胁** | SERN 冷蓝 | `#4A6A8A` | `#3A5A7A` |
| **信息/中性** | Mayuri 柔蓝 | `#6B8FA3` | `#4A7A94` |

## 2. 材质语言 · Material Language

Steins;Gate 的材质语言是 **2010 年秋叶原 × 模拟科技 × 实验室**：

| 材质 | Steins;Gate 来源 | 设计含义 |
|------|-----------------|---------|
| **CRT 显示器** | PhoneWave 搭载的 IBM 5100 外接 CRT | 扫描线、荧光余晖、微闪烁、圆角边框 |
| **辉光管 (Nixie Tube)** | 世界线变动率探测仪 | 暖橙灯丝发光、暗底色、7 段数字显示 |
| **白炽灯** | Lab 天花板灯泡 | 暖黄照明、色温 ~2700K、产生浓影 |
| **旧木** | Lab 的桌子、柜子 | 暗棕、有纹理、有温度 |
| **拉丝金属** | 电话微波炉外壳、CRT 壳体 | 微氧化、散射反射、非光滑 |
| **线缆与杂物** | Lab 的桌上山下 | 黑色橡胶线、裸露电路板、原型机 |
| **纸张** | 研究笔记、DMail 记录 | 微黄纸、墨迹、手写质感 |
| **玻璃/烧杯** | 实验设备 | 反射、模糊透明、微绿调 |
| **Dr. Pepper** | 冈部的饮料 | 红罐——反复出现的色彩锚点 |

**设计含义**：bili2insight 的 UI 不应是"扁平现代"的。应该有材质深度——
Hover 时表面微微发光（白炽灯效果），边框有微妙的暖调，卡片有"纸面"纹理感。
这不是 `box-shadow` 的简单叠加，而是材质氛围的系统构建。

## 3. 视觉母题 · Visual Motifs

### 3.1 世界线 (World Lines)

剧中将平行世界线可视化为**发光的细线/弦在空间中汇聚**。多线汇聚为一线，
一线分裂为多线。

视觉表现：纤细的发光路径；多条线向一个点收敛；线与线之间纠缠/分离。

**设计含义**：bili2insight 中可以使用细光线作为分隔、连接、流程指示。
加载动画可以是世界线的汇聚/发散。页面间的过渡可以是线性的（line transition，
而非 crossfade）。

### 3.2 世界线变动率探测仪 (Divergence Meter)

| 特性 | 表现 |
|------|------|
| 显示方式 | **辉光管**（Nixie tube）– 7 段数字，暖橙灯丝发光 |
| 底色 | 暗（黑或深棕） |
| 数字 | `1.048596` —— 这是 α 世界线的初始值 |
| 情感 | 冷峻的客观数据，承载着人与人之间的全部重量 |

**⚠️ 当前实现错误**：bili2insight 的 divergence 读数是 `#6fb584`（sage green）。
正确的颜色应该是**辉光管橙** `#FF8C42`。辉光管从未发出绿色光——它们发出的是
氖气放电的暖橙/红橙色。

### 3.3 电话微波炉（暂定）· PhoneWave (name subject to change)

视觉构成：微波炉（拉丝金属）+ IBM 5100 外接 CRT（绿字黑底）+ 翻盖手机 + 线缆
- 这是"高端科技 × 破烂装备"的终极表达
- 不是 sleek Apple 风——是 **hacky、拼凑的、真实的**

### 3.4 齿轮 / 发条 (Gears / Clockwork)

OP 和意象中反复出现的机械齿轮，象征**时间是机械的、可被干预的系统**。
但齿轮在 Steins;Gate 中是**象征性的**，而非装饰性的。原 CLAUDE.md 把齿轮 SVG
放在 logo 里的做法是正确的，但 gear icon 只是冰山一角。

### 3.5 翻盖手机 · Phone Trigger

冈部的手机是老式翻盖——D-Mail 的物理触发器。这是 **2010 年的技术锚点**。

### 3.6 @channel

剧中使用的匿名 BBS——复古的论坛 UI、绿色/白色文字在深色背景上。这是
"信息交换"的界面原型，也是 bili2insight 的"观测记录"功能的参考。

## 4. 场景氛围映射 · Scene → UI Mode

| Steins;Gate 场景 | 对应 UI 模式 | 关键色 | 氛围 |
|-----------------|------------|--------|------|
| **Lab 夜间** — 只有 CRT 和世界线仪的微光 | **暗色模式** | 暖深棕/炭黑 + CRT绿 + 辉光管橙 | 沉浸、专注、观测 |
| **Lab 午后** — 阳光透过百叶窗 | **亮色模式** | 奶油白/暖纸色 + 金色 + 栗红 | 清晰、工作、日常 |

| **Steins;Gate 世界线** — 金色小时光 | **完成/成功状态** | 金黄 + 暖白 | 圆满的、确认的 |

## 5. 牧濑红莉栖 · 设计锚点深度分析

Kurisu 不是"一个角色色板"——她是 Steins;Gate 视觉体系中**饱和色的来源**。

### 5.1 色彩张力

在 Lab 的暖棕/暗影背景中，Kurisu 的栗红色头发是**唯一高饱和度元素**。
这种对比不是偶然的——它是刻意为之的视觉层级：**Lab 是画布，Kurisu 是焦点。**

### 5.2 红 × 紫 = 知性

Kurisu 的色彩信息不是"激情"、不是"危险"——是 **知性的热度**。
栗红 `#8B3A3A`  + 紫罗兰眼 `#6B5B9E` = **红移向紫**（subtle red-purple shift）。
这种色彩组合传达的是：深度思考、内敛的强烈、科学家式的热情。

### 5.3 白大褂的暖白

Kurisu 的白大褂从不是纯白 `#FFFFFF`——剧中几乎没有任何东西是纯白的。
它被白炽灯染成暖白 `#F5F0EB`，带有微妙的 Amber shift。这是**有温度的科学**。

### 5.4 设计映射

- **Kurisu 栗红** → 主交互信号（按钮、link、选中态、进度条）
- **Kurisu 紫罗兰** → selected/visited 态（已选择的、已观测的）
- **Kurisu 暖白** → surface/bg 在亮色模式下（不是纯白）
- **红 × 紫的渐变** → 重要的强调元素（渐变条、highlight）

## 6. VN 界面参考 · Visual Novel UI

Steins;Gate VN（原版）的界面风格：

| 元素 | 外观 |
|------|------|
| **文本框** | 暗色半透明底，白色文字，暖调 |
| **系统菜单** | 深灰底 + 蓝绿/青 accent |
| **存档界面** | 深色网格 + 缩略图 + 日期 |
| **手机界面** | 老式翻盖手机 UI——青色 LCD 背光、像素字体 |
| **Loading** | 齿轮转动动画 |
| **章节过渡** | 黑色 + 白色衬线体标题 + 微光 |
| **配色基调** | 深暗基底 + 青/蓝灰 accent（VN 比动画更冷调） |

**注意**：VN 的 UI accent 是**青蓝/teal**（#4AA3B8 左右），不是 sage green。
原 CLAUDE.md 的 sage green 即使在 VN 参考下也不准确。

## 7. bili2insight 设计系统修正

### 7.1 当前错误汇总

| 当前 CLAUDE.md 定义 | 问题 | 应为 |
|-------------------|------|------|
| 品牌色 `#6fb584` sage green | Steins;Gate 没有 sage green 品牌色 | Kurisu 栗红 `#8B3E3E` 为主交互色；CRT 绿 `#4AE54A` 为技术色 |
| 暗色 bg `#111316` (h216 冷蓝灰) | 与 Lab 的暖暗氛围冲突 | 暖深棕 `#1A1512` ~ `#1E1B18` |
| 暗色 surface `#181b20` (h218) | 同上 | `#24211D` (暖暗棕) |
| 世界线读数 `#6fb584` 绿色 | 辉光管是橙色的 | 辉光管橙 `#FF8C42` |
| light mode bg `#f5f3ef` (h40 暖) | 这是暖黄，接近 Lab 日间但色温不统一 | 已完成修正 (Direction A)，但应微调为更暖的 `#F5F0E8` |
| 暗色文字 `#e3e0d9` (h42 暖) | 暖文字配冷灰底 = 不融和 | 暖文字应配暖底 |
